
TP 4 - Programmation Orientée Objet en PHP

Ce dépôt contient l'ensemble des exercices réalisés pour le TP 4 portant sur la programmation orientée objet (POO) en PHP. 
L'objectif de ce travail est de prendre en main les concepts de base de la POO .

Prérequis

PHP 8.1 ou une version supérieure (nécessaire pour readonly et la promotion de propriétés).

Un terminal ou un serveur local pour exécuter les fichiers.

Structure du projet

partie0.php : Découverte des classes, des objets et de la variable $this.

partie1.php : Gestion de la visibilité (public, private, protected) et encapsulation.

partie2.php : Utilisation des constructeurs, de la promotion de propriétés et des destructeurs.

partie3.php : Surcharge de propriétés avec les méthodes magiques (__get, __set, __isset, __unset).

partie4.php : Représentation textuelle d'un objet avec __toString.

partie5.php : Sérialisation et sécurité avec __serialize et __unserialize.

partie6.php : Héritage, réutilisation de méthodes avec parent:: et utilisation de final / readonly.

partie7.php : Résolution d'un exercice pratique sur la gestion de comptes bancaires.

reponses.md : Réponses rédigées aux questions théoriques posées dans le TP.

Execution du code

Vous pouvez exécuter n'importe quel fichier directement depuis votre terminal :

php partie1.php


Ou bien lancer le serveur interne de PHP depuis le dossier du projet :

php -S localhost:8000


Puis ouvrir votre navigateur à l'adresse http://localhost:8000/partie1.php.
